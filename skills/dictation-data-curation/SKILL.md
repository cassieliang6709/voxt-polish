# 语音润色语料清洗工作流

清洗用于微调本地语音润色模型（如 Qwen3-0.6B）的 `ASR 原文 → 目标润色文本` 语料对。核心原则：**数据干净比盲目换大模型更有效**；不要把上游工具的幻觉、术语错纠和口语残片教给小模型。

## 1. 六步清洗检查表（按顺序执行）

1. **剔除空录音与假输出**：检查 `asr` 为空或极短、但标注侧凭空输出内容（如空录音输出 `I get`）的样本，直接删除并在报告里写明删除原因。
2. **扫描英文与技术术语错纠**：提取 `asr` 和 `typeless` 的英文词差集，加上常见同音词黑名单，重点排查四类错：
   - 专业词被硬改成别的词（如 `MLA → MQA`、`SGLang → SG&A`、`Terminal → Termius`、`PostToolUse → pause to use`）
   - 专有名词被凭空替换（如 `Obsidian → 飞书文档`、`Google Cloud → Global Core`、`Zero to SGL → Zero to Hero`）
   - 组合技能/项目名被删词或写散（如 `iPhone use → iPhone`、`One Day / OneDay → 1Day`、`P Stack → pstack`、`CS336 → 3336`）
   - ASR 同音错词未修复（如 `即即 QA → GQA`、`J.K.V → GQA`）
3. **字符级 Diff 抓语义颠倒与同音误纠**：对全量样本跑 `SequenceMatcher` 替换段扫描，专门抓隐蔽的中文改错，例如：
   - 语义完全写反（如「默认是英语，不是默认是中文」被写反）
   - 人称篡改（如「我要晚上处理」被改成「他主要帮忙处理」）
   - 中文同音词改错（如 `手势 → 首选`、`新知 → 机制`、`心情弹窗 → 新进弹窗`）
   - 残留口吃叠字（如 `那我我现在`）
4. **清理尾句截断残片与误加问号**：
   - 删除录音松键截断留下的不完整尾句（如句末多出的 `我在`、`就是`、`就是……`）。
   - 检查陈述句末尾被强加的 `？`（如 `我试试？`、`看一眼？`、`权衡一下？`），还原为陈述句。
5. **清理无信息量的口语「然后」**：
   - 删除段首、句号/问号后以及无时间先后含义的逗号后「然后」（如「我看的是 Home Assistant，然后它并没有操控」→「我看的是 Home Assistant，它并没有操控」）。
   - 保留表示真实步骤先后的「先……然后……」和「然后再……」。
6. **补齐结构与统一排版**：
   - 明确口述分点（如「第一…第二…」「第一个事情…」「二是…第三个是…」）却散落成段的条目，规整为 `1. 2. 3.` 列表；子列表统一用 `- `。
   - 中英文及中文与数字之间统一加单空格（跳过 URL）；英文双引号统一为中文弯引号 `“”` 并清除引号外侧多余空格；清理连续双空格、标点前空格、行尾空格与多余空行。
7. **轻意译、不总结（权衡可读性与原话保真）**：
   - **该改的**：语序破碎、缺宾语或口语瞎凑导致外人看不懂的表达（例如「不跟它搞 Apple 这个点了」→「不用 Apple 这套了」，「写一些你觉得需要遵守的点」→「过程中需要遵守的规则你自己定好写下来」，「需要你提交的东西你都给它」→「需要提交的文件你直接处理好」）。
   - **不该改的**：绝不压缩成总结腔或官方腔（例如不要把「我好难受啊」删掉，也不要把「说实话我有点无法接受」改写成「觉得 UI 存在问题」）；保留说话人的语气情绪与大部分原词，既让读者一眼看懂，也维持端侧 `ngram-simple` 投机解码的抄词命中率。
8. **小数据集必须 100% 分块逐行通读**：500 条以内的语料不能只靠正则和低相似度启发式筛查。把全集切成每块约 90 条通读，专抓启发式漏掉的隐蔽语义篡改（如「投简历的能力特别弱 → 接投简历的人特别多」、「不想让你做了 → 不想公开了」、「哦 → 爸」）。

## 2. 产物与人工走查

每次清洗必须输出三份产物，并直接打开走查页让用户确认后再开训：

1. **清洗后数据**：`pairs_clean.jsonl`（不覆盖原始 `pairs.jsonl`）。
2. **变更清单**：`clean_report.md`，逐条列出改动类别、原因、ASR 原文、原标注、清洗后结果。
3. **3 列对照走查页**：`review_db.html`（`ASR 原文 | 原标注 | 清洗后`，支持按「已清洗 / 术语幻觉 / 补 1.2.3. / 全部」筛选与关键词搜索）。

## 3. 训练与验证边界

- **按时间切分留出集**：最早数据作训练集、最新 N 条（如 40 条）作留出集，不随机打乱防止时间泄露。
- **保留对照实验**：清洗前后用相同超参和留出集做「零样本 vs 原始数据 SFT vs 清洗数据 SFT」三组对照，用真实案例验证术语乱替换是否下降。
- **训练细节**：对 Qwen3 系列关闭 `<think>`（`enable_thinking=False`），只对助手输出和 `<|im_end|>` 计算 loss，避开 LoRA 冻结终止符导致的不终止问题。
